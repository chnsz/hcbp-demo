# 简介

## 什么是设备接入（IoTDA）

设备接入服务（IoT Device Access，IoTDA）是华为云提供的物联网平台服务，为海量设备提供安全可靠的连接、数据采集与命令下发能力。IoTDA支持多种接入协议与网络方式，帮助用户快速构建物联网应用，实现设备与云端的双向通信。

IoTDA提供设备管理、产品模型、规则引擎、数据流转等核心能力。通过规则引擎，用户可以将设备上报的数据按需转发至华为云上的其他服务（如OBS、DIS、FunctionGraph等），实现数据的存储、分析与处理；同时，IoTDA还提供数据流转控制策略与数据积压策略，用于限制租户级数据转发的TPS上限，并对转发数据的积压大小和积压时间进行控制，保障数据转发链路的稳定性。

借助IoTDA，企业无需自建物联网平台即可快速完成设备接入与数据上云，降低物联网应用的开发与运维成本，并为后续的设备管理、数据分析和业务创新奠定基础。
