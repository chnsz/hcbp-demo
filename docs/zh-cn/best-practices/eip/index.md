# 简介

## 什么是弹性公网IP（EIP）

弹性公网IP（Elastic IP，EIP）是华为云提供的一种可独立申请和绑定的公网IP地址资源，为云上资源提供访问公网和被公网访问的能力。EIP可以与弹性云服务器、裸金属服务器、弹性负载均衡、NAT网关、虚拟IP等云资源灵活绑定与解绑，帮助用户按需构建公网访问入口，无需为每台服务器单独配置固定的公网地址。

EIP支持按带宽计费和按流量计费两种计费模式，并可与共享带宽配合使用。共享带宽可以将多个EIP加入同一份带宽资源中，实现带宽的复用与共享，从而降低公网带宽成本并提升带宽利用率。EIP还支持绑定企业项目、设置标签、配置公网边界组等能力，满足企业级资源管理与成本分摊需求。

通过EIP，用户可以灵活地为云上业务提供稳定、安全、可管理的公网访问能力，并结合共享带宽、带宽调整等特性，实现公网出口的弹性伸缩与成本优化。
