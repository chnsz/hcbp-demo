# 简介

## 什么是数据安全中心（DSC）

数据安全中心（Data Security Center，DSC）是华为云提供的一站式数据安全治理服务，围绕数据全生命周期提供敏感数据识别、数据脱敏、数据水印、数据安全审计等能力，帮助企业构建可视、可控、可审计的数据安全防护体系，满足《数据安全法》《个人信息保护法》等合规要求。

DSC支持对云上数据库、大数据、对象存储等多种数据源进行自动化的敏感数据扫描与分类分级，帮助用户快速发现敏感数据分布并识别潜在风险。在此基础上，DSC提供静态脱敏与动态脱敏能力，支持内置算法与自定义算法，可对身份证号、手机号、银行卡号等敏感字段进行掩码处理，保证数据在开发、测试、共享等场景中的安全性。

通过DSC，企业可以统一管理数据安全策略、跟踪数据流转路径并生成合规审计报告，从而降低数据泄露风险，提升数据安全治理效率，为后续的数据安全运营与合规检查工作奠定坚实基础。
