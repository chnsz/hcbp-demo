# 简介

## 什么是NAT网关（NAT Gateway）

NAT网关（NAT Gateway）是华为云提供的高性能、高可用的网络地址转换服务，为虚拟私有云（VPC）内的云服务器、裸金属服务器等资源提供访问公网以及被公网访问的能力。NAT网关通过SNAT和DNAT两种转换方式，在不改变云上资源私网地址的前提下实现与公网的互通，帮助企业以更安全、更经济的方式构建云上网络出入口。

NAT网关支持SNAT（源网络地址转换），使VPC内的多台云服务器共享弹性公网IP主动访问互联网，无需为每台服务器单独绑定公网IP；同时支持DNAT（目的网络地址转换），将公网EIP上的访问流量按端口映射到VPC内后端服务器的私网地址与端口，使内部服务可以安全地对外提供访问。NAT网关提供多种规格，可根据业务流量规模灵活选择，并支持按需弹性扩展。

借助NAT网关，企业可以统一管理云上资源的公网出入口，降低公网IP资源消耗与安全暴露面，并结合安全组、网络ACL等能力构建分层的网络安全防护体系，为后续的网络运维与成本优化奠定基础。
