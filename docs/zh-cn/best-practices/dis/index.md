# 简介

## 什么是数据接入服务（DIS）

数据接入服务（Data Ingestion Service，DIS）是华为云提供的实时数据接入服务，为处理或分析流式数据的用户提供了全托管的、高性能、高可靠的数据接入能力。DIS可广泛应用于实时监控、日志分析、IoT设备数据采集等场景，帮助用户轻松构建基于流式数据的应用。

DIS提供了多种数据接入方式，支持从多种数据源（如应用程序、IoT设备、日志文件等）实时采集数据，并将数据流式传输到华为云上的其他服务（如对象存储服务OBS、数据湖探索DLI、MapReduce服务MRS等）进行进一步处理和分析。DIS支持自动扩缩容，可根据业务流量变化自动调整通道的分区数量，确保数据接入的稳定性和成本效益。

通过使用DIS，用户可以快速构建实时数据处理管道，实现数据的实时采集、传输和分发，为实时监控、实时分析、告警触发等业务场景提供可靠的数据基础。
