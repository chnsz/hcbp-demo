# 简介

## 什么是数据接入服务（DIS）

数据接入服务（Data Ingestion Service，DIS）是华为云提供的实时数据接入服务，用于将海量数据实时采集并传输至云上。DIS提供完全托管的通道能力，支持多种数据源与数据类型的接入，帮助用户构建从数据采集、传输到处理分析的实时数据管道，广泛应用于日志采集、IoT数据接入、实时监控与流式分析等场景。

DIS以通道（Stream）为核心概念，通道负责承载数据的写入与读取，并可通过分区数量、数据保留周期等参数满足不同吞吐量与可靠性要求。DIS支持普通通道与高级通道两种类型，支持自动扩缩容分区，并支持CSV、JSON、BLOB等多种数据类型以及zip、gzip、snappy、lz4、zstd等压缩格式，帮助用户灵活适配不同的数据格式与业务规模。

通过DIS，用户可以按需创建和管理数据接入通道，结合标签管理实现资源的分类与成本分析，降低数据接入的开发与运维成本，为后续的实时数据处理与分析奠定基础。
