# 简介

## 什么是视频点播（VOD）

视频点播（Video on Demand，VOD）是华为云提供的一站式视频点播服务，面向音视频网站、在线教育、电商直播、企业培训等场景，提供从音视频上传、转码、存储、加速分发到播放的端到端能力。用户无需自建复杂的音视频处理与分发系统，即可快速构建稳定、流畅、安全的视频点播业务。

视频点播支持多种上传方式，包括控制台上传、API/SDK上传以及URL拉取上传，并支持媒资分类管理、音视频转码、截图、水印、加密、CDN加速分发和播放鉴权等能力。通过媒资分类，用户可以对海量音视频资源进行分组管理，便于检索与维护；通过转码模板与工作流，用户可以将源文件转码为适配不同终端与网络环境的播放格式。

借助视频点播服务，企业可以按需弹性扩展音视频处理与分发能力，降低自建系统的运维成本，并通过CDN加速与播放鉴权保障视频播放的流畅性与内容安全，为在线视频业务的持续运营提供坚实基础。
