# 简介

## 什么是企业项目管理服务（EPS）

企业项目管理服务（Enterprise Project Management Service，EPS）是华为云提供的企业级资源管理服务，旨在帮助企业以项目为单位对云上资源进行统一规划、分类和授权。通过企业项目，企业可以将不同业务、部门或环境的资源划分到独立的项目下，实现资源的分组管理、成本归集和权限隔离，从而提升云上资源管理的规范性与效率。

EPS 支持企业项目的创建、启用、禁用和删除等全生命周期管理，并可与统一身份认证服务（IAM）配合，基于企业项目维度为用户和用户组授予精细化的访问权限。企业项目还支持与标签、成本中心等能力协同，帮助企业实现资源分类、成本分摊和合规审计。

借助 EPS，企业能够构建清晰的多项目资源管理架构，为后续的资源治理、成本优化和运维管理奠定坚实基础。
