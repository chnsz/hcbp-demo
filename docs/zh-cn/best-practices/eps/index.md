# 简介

## 什么是企业项目管理服务（EPS）

企业项目管理服务（Enterprise Project Management Service，EPS）是华为云提供的企业级资源管理服务，支持企业以项目为维度对云上资源进行分组、授权和成本核算。通过企业项目，企业可以将不同业务、部门或环境的资源划分到相互隔离的项目中，实现资源的逻辑隔离与统一管理，满足多业务、多团队协同场景下的管理需求。

EPS提供企业项目的创建、修改、启用、禁用和删除等全生命周期管理能力，并支持与企业组织架构、统一身份认证服务（IAM）策略相结合，实现按项目维度的精细化权限控制。同时，企业项目可与成本中心联动，帮助企业对不同项目的资源消耗进行独立核算与成本分摊。

借助企业项目，企业能够建立清晰的资源归属关系，简化资源检索与运维管理，并为后续的合规审计、成本优化和自动化治理奠定基础。
