# 简介

## 什么是媒体处理中心（MPC）

媒体处理中心（Media Processing Center，MPC）是华为云提供的一站式媒体处理服务，面向音视频内容的生产、处理与分发场景，提供转码、截图、水印、视频加密、音频提取等能力。MPC基于云上弹性计算资源，帮助用户将上传的源音视频文件快速转换为适配不同终端、不同网络环境的输出格式，无需自建和维护转码集群。

MPC支持多种主流音视频编码格式与封装格式，提供预置的转码模板与自定义转码模板，用户既可以直接使用系统模板快速完成转码，也可以按业务需求灵活定义输出格式、音频参数与视频参数。同时，MPC支持转码模板组、转码任务、转码消息通知等能力，便于将媒体处理流程集成到现有的业务系统中。

通过MPC，企业可以显著降低音视频处理的开发与运维成本，提升内容分发效率，广泛应用于在线教育、视频点播、直播回看、企业培训等场景。
