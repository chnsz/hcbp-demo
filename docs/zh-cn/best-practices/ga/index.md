# 简介

## 什么是全球加速（GA）

全球加速（Global Accelerator，GA）是华为云提供的全球网络加速服务，依托华为云遍布全球的接入点与骨干网络，为用户的互联网应用提供就近接入与全球加速能力。GA通过将用户流量从最近的接入点引入华为云骨干网，并经由优质骨干链路转发至源站，有效降低跨地域、跨运营商访问的时延与抖动，提升业务的访问体验与稳定性。

全球加速支持创建加速器并配置IP地址集合，通过监听器定义需要加速的协议与端口范围，再结合终端节点组将流量分发至不同区域的源站，实现全球范围内的流量调度与就近接入。GA支持IPv4与IPv6双栈接入，并可与弹性负载均衡、弹性云服务器等云资源配合使用，满足游戏加速、跨境访问、全球业务部署等多种场景需求。

在运维层面，全球加速提供访问日志能力，可将监听器的访问请求信息投递至云日志服务（LTS）进行统一存储与分析，帮助用户排查访问异常、分析流量特征并满足安全审计要求，为全球加速业务的持续稳定运行提供有力支撑。
