# 简介

## 什么是云防火墙（CFW）

云防火墙（Cloud Firewall，CFW）是新一代的云原生防火墙，提供云上互联网边界和VPC边界的防护，包括实时入侵检测与防御、全局统一访问控制、全流量分析可视化、日志审计与溯源分析等，同时支持按需弹性扩容、AI提升智能防御能力、灵活扩展满足云上业务的变化和扩张需求，极简应用让用户快速灵活应对威胁。

CFW支持基于五元组、域名、应用及IPS规则设置访问控制策略，可对互联网边界和VPC边界的南北向、东西向流量进行精细化管控，集成华为云威胁情报与AI入侵防御引擎，为云上业务提供网络安全防护基础能力。
