# 简介

## 什么是GaussDB

GaussDB是华为云提供的高性能、高可用、高安全的企业级分布式关系型数据库服务，基于华为在数据库领域多年的技术积累与软硬件协同优化能力构建，支持集中式和分布式两种部署形态，能够满足从中小规模业务到海量数据核心系统的多样化需求。

GaussDB完全兼容主流数据库生态，支持标准SQL以及存储过程、触发器、自定义函数等高级特性，并提供高可用架构、自动备份与恢复、容灾切换、读写分离、弹性扩容等企业级能力，帮助用户在云上快速构建稳定可靠的数据底座。

在安全与运维方面，GaussDB提供客户端接入认证（HBA）配置、细粒度权限管理、透明加密、审计日志等安全能力，并支持通过云监控、云日志等服务实现全方位的可观测性，帮助企业在保障数据安全合规的同时降低数据库运维成本。
