# 简介

## 什么是数据仓库服务（DWS）

数据仓库服务（Data Warehouse Service，DWS）是华为云提供的企业级云数据仓库服务，基于华为云基础设施构建，面向海量数据分析场景，提供高性能、高可靠、弹性扩展的数据仓库能力。DWS 采用分布式架构与列式存储技术，能够高效处理 PB 级数据的复杂查询与分析，帮助企业快速构建数据仓库、数据集市和实时分析等业务。

DWS 提供多种集群形态与规格，支持标准数仓、实时数仓、云数仓等多种部署模式，并兼容标准 SQL 与主流数据库生态工具，便于用户平滑迁移现有数据仓库业务。同时，DWS 提供自动备份、监控告警、弹性扩缩容、事件订阅等企业级运维能力，帮助用户在保障业务连续性的同时降低运维成本。

通过 DWS，企业可以将分散的业务数据集中存储与分析，挖掘数据价值，支撑经营决策与业务创新，是构建云上数据平台的重要基础服务。
