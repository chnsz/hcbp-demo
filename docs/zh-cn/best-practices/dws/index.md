# 简介

## 什么是数据仓库服务（DWS）

数据仓库服务（Data Warehouse Service，DWS）是华为云提供的在线联机分析处理（OLAP）数据库服务，基于华为云基础设施构建，面向企业级数据仓库场景，提供海量数据的快速查询与分析能力。DWS 采用分布式架构与列式存储技术，能够高效处理 PB 级数据，帮助企业在云上快速构建高性能、高可靠的数据分析平台。

DWS 提供多种集群形态与规格，支持标准数仓、实时数仓、IoT 数仓等不同场景，并兼容 PostgreSQL 生态，便于业务平滑迁移。DWS 具备弹性伸缩、自动备份、监控告警、容灾等企业级能力，可满足从中小规模到超大规模数据分析业务的多样化需求。

在运维层面，DWS 提供集群事件订阅、告警通知、性能监控等能力，帮助运维人员及时感知集群的扩容、缩容、重启、故障等关键事件，从而快速响应并保障业务的连续性与稳定性。
