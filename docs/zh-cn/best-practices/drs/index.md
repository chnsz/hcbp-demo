# 简介

## 什么是数据复制服务（DRS）

数据复制服务（Data Replication Service，DRS）是华为云提供的一站式数据复制服务，致力于帮助用户实现数据库的实时同步、迁移与灾备。DRS支持多种主流数据库引擎之间的数据流动，包括关系型数据库、文档数据库等，能够在业务不停机的前提下完成数据的平滑迁移，保障业务的连续性与数据的一致性。

DRS提供实时迁移、实时同步、数据订阅和备份迁移等多种能力，覆盖上云迁移、跨区域容灾、多活容灾、数据回流等多种典型场景。通过图形化的任务管理界面与灵活的迁移策略配置，用户可以方便地定义源端与目标端连接、选择迁移对象、设置过滤规则，并实时监控迁移进度与数据一致性。

在运维层面，DRS提供任务监控、告警通知、数据比对与修复等能力，帮助用户及时发现并处理迁移过程中的异常，降低数据迁移与同步的运维复杂度，为业务的稳定运行提供有力保障。
