# 简介

## 什么是图引擎服务（GES）

图引擎服务（Graph Engine Service，GES）是华为云提供的一站式图数据管理与分析服务，面向社交网络、知识图谱、金融风控、推荐系统等场景，提供千亿级点边的图数据存储、毫秒级查询与图分析能力。GES将图数据的存储、计算与分析能力封装为云服务，帮助用户无需自建图数据库集群即可快速构建图应用。

GES支持多种图规格与CPU架构，提供图实例的创建、备份、恢复、导入导出等全生命周期管理能力，并支持HTTPS加密访问与数据加密算法配置，满足不同规模与安全等级的业务需求。用户可以通过控制台或API灵活管理图实例，按需调整规格，降低图应用的构建与运维门槛。

借助GES，企业可以将复杂的关系网络转化为可查询、可分析的图数据资产，快速挖掘数据之间的关联价值，为智能推荐、反欺诈、知识推理等业务提供支撑。
