# 简介

## 什么是云性能测试服务（CPTS）

云性能测试服务（Cloud Performance Test Service，CPTS）是华为云提供的性能测试服务，旨在帮助用户对云上应用进行压力测试，评估系统在高并发场景下的性能表现。CPTS支持模拟真实用户行为，提供多种压测模式，帮助用户发现系统瓶颈，优化应用性能。

CPTS提供了完整的性能测试解决方案，包括测试工程管理、测试任务编排、性能指标监控和测试报告生成等功能。用户可以通过CPTS快速创建测试项目，配置测试任务，执行压力测试，并获取详细的性能分析报告，从而保障业务系统的稳定性和可靠性。

CPTS还支持与华为云其他服务集成，如云监控、日志服务等，帮助用户全面监控和分析测试过程中的系统状态。通过CPTS，用户可以高效地进行性能测试，提升应用质量，降低运维风险。
