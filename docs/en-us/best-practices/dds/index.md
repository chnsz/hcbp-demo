# Introduction

## What is Document Database Service (DDS)

Document Database Service (DDS) is a high-performance, highly reliable, and secure distributed document database service provided by Huawei Cloud. It is fully compatible with the MongoDB protocol and supports multiple deployment architectures such as replica set, cluster, and single node, making it suitable for various business scenarios. DDS provides enterprise-level features such as automatic backup, monitoring and alarming, and elastic scaling, helping users easily build and manage document databases, reduce O&M costs, and improve business efficiency.

DDS supports multiple database versions and storage engines, and provides a rich set of instance specifications and node types to meet business requirements of different scales and performance. In addition, DDS provides capabilities such as data backup and recovery, disaster recovery switchover, and security auditing to ensure data security and business continuity.

With DDS, users can quickly deploy highly available document databases, achieve reliable data storage and efficient access, and support core businesses in industries such as the Internet, IoT, gaming, and finance.
