# Introduction

## What is Resource Formation Service (RFS)

Resource Formation Service (RFS) is an Infrastructure as Code (IaC) service provided by Huawei Cloud, helping users define, orchestrate, and automatically deploy cloud resources in a code-based manner. Through template-based resource descriptions, RFS packages complex combinations of cloud resources into reusable templates, enabling standardized delivery and consistent management of infrastructure while reducing the risk of errors caused by manual configuration.

RFS supports the creation, update, and deletion of templates as well as previewing execution plans, allowing users to clearly understand resource changes before execution and complete resource orchestration in a safe and controllable way. In addition, RFS provides private module capabilities, allowing users to package a set of templates into standardized modules and manage them with module versions, making it easy to share and reuse infrastructure code across teams and projects.

With RFS, enterprises can turn infrastructure deployment processes into maintainable and traceable code assets. Combined with version management and automated execution, this lays a solid foundation for subsequent resource governance, compliance auditing, and continuous delivery.
