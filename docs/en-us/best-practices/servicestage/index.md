# Introduction

## What is ServiceStage

ServiceStage is a one-stop application hosting platform provided by Huawei Cloud, delivering full lifecycle management capabilities for enterprise and cloud-native applications, covering application development, build, deployment, and operations. ServiceStage supports multiple deployment forms such as virtual machines, containers, and serverless, helping enterprises quickly build and run applications on the cloud while reducing the complexity of application migration and operations.

ServiceStage provides core capabilities including application orchestration, environment management, configuration management, microservice governance, canary release, and auto scaling. With configuration groups and configuration files, users can centrally manage application configurations and reuse them across environments; with microservice engine and governance capabilities, users can build highly available and observable distributed application systems.

With ServiceStage, enterprises can standardize the application delivery process, achieve consistent delivery from code to runtime environment, and lay a solid foundation for subsequent application operations, monitoring, and governance work.
