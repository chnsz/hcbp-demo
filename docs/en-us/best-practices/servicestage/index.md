# Introduction

## What is ServiceStage

ServiceStage is a one-stop application management service provided by Huawei Cloud, delivering full lifecycle management for enterprise and cloud-native applications, including development, build, deployment, governance, and operations. ServiceStage shields users from underlying infrastructure differences, enabling rapid application onboarding and unified management while reducing the complexity of application delivery and operations.

ServiceStage provides core capabilities such as application management, component management, environment management, configuration management, and microservice governance. It supports multiple deployment forms including virtual machines, containers, and serverless, is compatible with mainstream microservice frameworks such as Spring Cloud and Dubbo, and works with cloud services such as CSE, AOM, and LTS to build a complete application runtime and governance system.

With ServiceStage, you can centrally manage environment variables, startup parameters, and business configurations to separate configuration from code, and leverage capabilities such as canary release and full-link monitoring to improve application availability and O&M efficiency, supporting continuous delivery and stable operation of your business.
